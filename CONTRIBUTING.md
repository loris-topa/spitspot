# How to contribute?

This is my first FOSS project, and I want humans to feel at home here.
For the sake of our own sanity, I kindly ask you to refrain from using AI agents to work on this codebase.
If the last phrase triggered you, please just fork this project and do whatever you want with it. I don't care.

If you happen to be a considerate being and still want to use AI to assist you, and even spit out code for you, that's FINE.
I just ask you to follow one rule:
# Own what you ship.
Ok, there's not just one rule but you get the idea. Be respectful, kind, helpful, and so on.

Code and comments are in english: It's a reasonable collaborative standard.
Text of the application is in italian: i18n in this phase is premature optimization.
